# 비전 앵커 검증 (vision-anchor-verify) Planning Document

> **Feature**: 과분할 FP 제거 — 유료 비전 판정(무료 신호 3연속 기각 §74-d·e·§75-c 이후 유일 경로) · **Date**: 2026-07-22

## 1. 범위·발견

무료 시스템 F1 90.7의 잔여 오차 = 과분할 FP(발언자·행사장 등). §65 무료화 때 원클릭에서 분리된 **비전 판정 자산이 온전히 살아있음**: `OpenAITextClient.classifyAnchorShots`(untrusted-data 불변식·참조 이미지·검증 로직)와 자막 경로의 배선(예시 코퍼스 `loadAnchorExemplars`·배치 12장·확신 임계). 본 작업은 새 어댑터가 아니라 **비주얼 원클릭에의 재배선**이다.

## 2. 설계

- **체크박스** `news-cut-vision-check` "AI 비전 검증(유료)" — 초기 설계는 기본 OFF였으나, 오배제 0 확립(§92)·실기 F1 100(§93)을 근거로 **기본 ON으로 전환**(§96). 발동 조건은 체크 + AI 전송 동의 + API 키 세 가지 모두이고, 어느 하나라도 없으면 활동 로그 한 줄로 건너뛰고 무료 결과로 완주한다(§99). 해제 상태는 설정에 영속된다.
- **적용 지점**: `runNewsCutAutoFlow`의 `hybridAnchorTimes` 확정 직후·재스냅 전 — 확정 시각(t+1.2s) 프레임을 PNG로 내보내 `classifyAnchorShots`(참조=예시 코퍼스 ≤5장, 배치 12−refs)로 판정, **isAnchor=false·confidence≥0.6이면 제외**.
- **안전장치**: ①API 실패 시 경고 후 무료 결과 그대로(우아한 강하) ②통과 <3이면 필터 해제(미지 포맷 보호 — §77-a와 동일 철학) ③원클릭·분할만 모두 체크박스로만 발동.
- 비용: 회차당 확정 후보 10~25프레임 ≈ 배치 2~3회 호출.

## 3. 검증

- 게이트(1823)+check:news(분할 코어 불변 확인).
- 실기: FP 4건이 실측된 6/10 회차를 비전 ON 분할만으로 재실행 — 13→~9 아이템 기대. 키/쿼터 부재 시 강하 경로 확인도 유효 결과로 기록.

## 4. 리스크

| 리스크 | 완화 |
|---|---|
| OpenAI 쿼터/키 부재 | 강하 경로(경고+무료 결과) — 기능 자체는 항상 완주 |
| 비전이 진짜 앵커를 오제외 | confidence≥0.6에서만 제외 + 통과<3 해제 + 실기 재현율 확인 |
| 비용 우려 | 옵트인 기본 OFF + 라벨에 "(유료)" 명시 |
