# 자율 스케줄러 — 병목 무발생·개선 무중단 (2026-08-08 사용자 지시)

> "앞으로 병목이 발생하고 개선되지 않게 자체적으로 스케줄러 짜줘" — 이 문서가 그 스케줄러다.
> 매시 점검 크론은 이 문서의 큐를 평가해 최상위 실행 가능 항목을 기동한다. 세션이 재시작되면
> 이 문서부터 읽고 크론(매시 :23)을 다시 건다. 실사고 근거: 2026-08-08 04~19시, "신규 없음 +
> 사용자 부재 + Premiere 열화"가 겹치자 15시간 동안 점검만 반복되고 개선이 멈췄다.

## 원칙 네 가지

1. **대기 조건이 생기면 그 조건이 필요 없는 작업으로 즉시 전환한다.** "변화 없음" 보고만
   남기는 유휴 사이클은 스케줄러 실패다 — 매 사이클 반드시 하나를 실행한다.
2. **백로그는 항상 3개 이상 유지한다.** 소진되면 "발굴 사이클" 자체가 다음 작업이다.
3. **실기(단일 CDP 세션)와 자원이 겹치지 않는 작업은 병렬로 진행한다** — 실기 체인 중에도
   오프라인 분석·문서·다운로드는 돈다(단 빌드(npm run build/check)는 체인 중 금지 — dist 오염).
4. **서브에이전트는 항상 최대로 고용한다**(2026-08-09 사용자 지시). 실기 세션과 겹치지 않는
   일 — 프레임 판독, 대량 탐색, 코드 감사, 외부 자료 조사, 보고서 작성 — 은 **기본적으로
   에이전트에 위임하고 여러 명을 동시에 돌린다.** 혼자 순차로 처리하는 것이 기본값이 아니다.
   - 매 사이클 "지금 병렬로 돌릴 수 있는 조사·감사·판독이 무엇인가"를 먼저 묻는다.
   - 종류 제한 없다(general-purpose·Explore·code-analyzer·Plan 등 일에 맞는 것).
   - 위임해도 **판정·확정은 본인이 한다** — 라벨 확정은 본인 재검증 필수(§측정 규약),
     에이전트 보고는 1차 자료로만 쓴다.
   - 실기(단일 CDP)와 빌드는 위임 금지 — 세션·dist 충돌.

## 백로그 (2026-08-09 갱신 — 완료 시 취소선, 3개 미만이면 P4 발굴 강제)

**A. 데스크행 거리 게이트(최우선)** — FP 39건 전수 판독 결과 67%가 "앵커 없는 b-roll + 1줄
헤드라인 띠"다. 뱅크 거리를 **격자 최하단 행(데스크 영역)으로만** 재면 AUC 0.656 → 0.923.
오프라인 모의: 문턱 0.09~0.095에서 FP 학습 -35%·홀드아웃 -33%, §153 회차 하락 게이트 통과.
구현은 거리 함수 1개 + 후보 filter 1줄(재스캔·재학습 불필요), 8뉴스는 MW 전용 옵션으로 분리.
**주의**: 에이전트 모의는 [t, t+4] 최솟값 기준 — 제품의 shot mid 기준으로 문턱 재측정 필요.
산출물 `scratchpad/fp-analysis/`·`fp-desk-sim.mjs`.

**B. 인용 띠 필터 모닝와이드 이식** — 8뉴스에 이미 있고 검증된(라벨 315건 오판 0) 2줄 인용
띠 필터가 MW 경로에 연결돼 있지 않다. D형 FP 4건 대상, A와 상보(0721@812는 A가 못 잡음).
비용은 회차별 `.bandprobes.json` 생성 파이프라인.

**C. 라벨 결손 판정(사용자 확인 후보)** — FP로 분류된 C형 3건(7/29@822·7/15@316·7/16@1004)이
실은 라벨 누락일 수 있다(배경·주제가 직전 아이템과 완전히 다름). 프레임 재확인으로 판정.
사실이면 무료 정밀도 상한이 측정치보다 높다.

**D. 감사 잔여(2026-08-09 code-analyzer 12건 중 미시정)** — ①합집합 cap 0.09가 3계열 기준인데
뱅크는 7계열(자기 문서가 "뱅크 바뀌면 재측정" 규정, 4회 건너뜀) ②`runYieldMaxDist`가 같은
상수를 공유해 cap 재스윕이 양보 문턱을 함께 움직임 → 상수 분리 ③MW 앵커 블록 6~10초인데
스윕 step 8초·검증 프로브 +4/+7이 8뉴스(10~30초) 기준 → 짧은 블록에서 프로브가 블록 밖 ④
`mw-offline-gate.mjs`가 리포 밖(스크래치패드)에만 있어 사라져도 무신호 → `check:mw` 승격
⑤NaN fail-open(`refDist >= cap` 폴라리티) ⑥`preferPrimary:false` 무테스트.

**E. 에지 표현 실험(중장기·8뉴스 동결 주의)** — 같은 픽셀에서 luma 대신 **에지 채널**을 쓰면
교차회차 판별력 AUC 0.738 → 0.970(띠 영역 제외해도 0.918, 현행 96px 스캔 폭 유지 가능).
"판별 정보가 luma 격자에 없다"는 오래된 결론의 해법 후보. 제품 변경 0으로 오프라인 재스캔
→ 뱅크·모델 재구성 → 홀드아웃 판정까지 하고, 통과 시에만 제품화(공용 코드라 check:news 필수).
산출물 `scratchpad/repr-compare.mjs`.
