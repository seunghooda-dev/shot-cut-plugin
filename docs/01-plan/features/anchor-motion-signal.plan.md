# 시간적 움직임 신호로 과분할 억제 (anchor-motion-signal) Planning Document

> **Feature**: FP 억제 2차 시도 — anchor-left-feature(기각) 후속 · **Project**: shortflow-studio · **Date**: 2026-07-21
> **전제 지식**: ①하이브리드는 ∪ 결합이라 모델로 FP 제거 불가(§74) ②픽셀 매칭 필터는 의상 과민으로 기각(§74-d)

## 1. 가설

앵커 리드는 **고정 카메라 스튜디오 샷** — 2초 간격 샘플 사이 변화가 작고 국소적(앵커의 발화 동작)이다. 반면 FP 지점(발언·기자회견·유세·객석·헬기)은 카메라 이동·군중·큰 피사체 움직임으로 **변화가 크고 넓게 퍼진다**. 확정 앵커 시각의 리드 창 [t, t+4]에서 **움직임 총량·움직인 셀 비율**을 재면 TP/FP가 갈릴 것이다.

의상 문제(§74-d)와 다른 점: 이 신호는 참조와의 **일치**가 아니라 창 내부의 **시간적 변화만** 보므로 그날의 의상·세트와 무관하다.

## 2. 방법 — 실험 먼저, 제품화는 나중에 (§74-d 교훈)

지난번엔 src부터 구현하고 스윕에서 기각돼 전량 회귀했다. 이번엔 순서를 뒤집는다.

1. **오프라인 실험(스크래치패드만)**: 캐시 51회차에서 현행 예측의 TP/FP를 라벨로 판정하고, 각 시각의 창 [t, t+4] 움직임 지표를 계산해 **TP/FP 분포 분리도**를 먼저 본다.
   - 지표 후보: ①창 내 인접 샘플 프레임차 평균(motionMean) ②움직인 셀 비율(셀 diff>τ_cell 비율) ③왼쪽 밖 움직임 비율(우측 배경 비디오월 리스크 확인용)
2. **분리도가 있으면** 임계 스윕(전체 F1·R·홀드아웃 — 기준: F1↑, R≥93, 홀드아웃 무하락) → 통과 시에만 src 제품화(필터 함수+유닛+index.ts+lib).
3. **분리도가 없으면** 결과·분포 수치만 기록하고 종료(코드 변경 0).

## 3. 성공 기준

- 전체 51회차: FP 83 → 감소, R 93.8 유지(±1), F1 90.2 → 상승.
- 홀드아웃 4회차: 84.9 무하락.
- 미달 시 미반영(게이트 원칙) — 분포 수치는 후속 연구 자산으로 기록.

## 4. 리스크

| 리스크 | 대응 |
|---|---|
| 앵커 배경 비디오월(신형 세트)이 움직여 TP도 고움직임 | 지표 ③으로 사전 확인 — 왼쪽(앵커 위치) 제외 움직임만 보되, 그래도 겹치면 기각 |
| 정적 footage(건물 외경 단신) FP는 못 잡음 | 부분 개선도 수용 — FP 전량 제거가 목표 아님 |
| 2s 샘플 간격이 성겨 발화 동작이 크게 잡힘 | 분포에서 실측 판단 |

## 5. 실험 결과 (2026-07-21) — ❌ 분리도 없음, 기각

51회차 예측 TP 542 / FP 82의 리드 창 지표 분포(scratchpad/motion-experiment.mjs).

| 지표 | TP p50 | FP p50 | TP p90 | FP p90 |
|---|---|---|---|---|
| motion(창 평균 프레임차) | 0.024 | 0.030 | 0.037 | 0.074 |
| moving(움직인 셀 비율) | 0.094 | 0.097 | 0.160 | 0.392 |
| right(오른쪽 움직임) | 0.022 | 0.030 | 0.038 | 0.074 |

중앙값이 사실상 겹치고, FP 꼬리(p90)만 높다 — 어떤 임계도 TP 손실 없이 FP를 못 자른다(스코어 최적점 = 무제거). **원인: 리스크 1 실측 확정 — 앵커 배경 비디오월이 애니메이션이라 진짜 앵커 리드의 절반이 FP 수준으로 움직인다.** "스튜디오=정적" 가설 자체가 이 방송 세트에 안 맞음.

**결론**: 코드 변경 0으로 종료(실험 우선 설계의 목적 달성). 남은 FP 억제 경로는 ①비전 판정 재도입(위치·인물 프롬프트 — 유료) ②고해상 스캔(96x54→상향)으로 인물 위치 검출 — 둘 다 비용/성능 트레이드오프가 커 사용자 판단 필요.
