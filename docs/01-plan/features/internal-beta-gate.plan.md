# 내부 베타 출하 게이트 (internal-beta-gate)

2026-08-02 시작. 뉴스 분할 F1이 실측 천장(41회차 중 40회차 100)에 닿고 잔여가 자료 대기가
되면서, 프로젝트의 원래 목표인 **내부 베타 배포 가능 상태**를 다음 축으로 삼는다(사용자
선택, AskUserQuestion 2026-08-02).

## 1. 문제 — 기능은 다 있는데 "배포해도 되는가"가 답이 없다

기능 구현은 스코프 문서 기준 전부 출시 완료다. 남은 것은 `INTERNAL_BETA_SCOPE.md`의
"Premiere 설치 후 실제 Host 승인 조건" 5개 영역 검증과, 릴리스 체크리스트를 실제로 통과
가능한 상태로 만드는 것이다.

## 2. 완료 조건

1. Host 승인 조건 5개 영역이 각각 자동 프로브 또는 문서화된 수동 절차로 덮인다.
2. `BETA_RELEASE_CHECKLIST.md`의 [자동] 항목이 전부 스모크·게이트로 실측 통과한다.
3. 배포 문서 6종(README·ROADMAP·REQUIREMENTS_MATRIX·QA_CHECKLIST·SCOPE·USER_GUIDE)에
   현행 제품과 모순되는 서술이 없다.
4. CCX·SHA-256 증거가 최신 소스에서 재생성돼 있다.

## 3. 진행 상태 (2026-08-02)

| 승인 조건 | 상태 | 근거 |
|---|---|---|
| 패널 로드·재로드·수명주기 | **자동화 완료** | `listener-lifecycle`(탭 26클릭·증가 0) |
| 파일 권한·한글/공백 경로 | **자동화 완료** | `hangul-path-io`(왕복·이름보존·삭제) |
| 삽입 작업의 원본 보존 | **자동화 완료** | `source-untouched`(클립 든 guard 지문 불변) |
| 프로젝트·시퀀스 전환·autosave | **자동화 완료(부분)** | `sequence-switch-recover`·`status-truth`. 프로젝트 간 전환·autosave는 수동 |
| 실제 CCX 설치·버전 호환 | **대부분 완료(2026-08-03)** | UPIA CLI 설치 성공 → `Enabled ShortFlow Studio 1.0.0`(Premiere 26.3.0) 등록 확인, 개발판(UDT)과 공존·스모크 4/4. 잔여: Premiere 재시작 후 설치본 패널 열림·시리얼 키 게이트 육안 확인(수동 5분) |

완료 조건 2·3·4는 2026-08-02 배치에서 충족 — 스모크 11/11, 문서 모순 7계열 시정(Explore
감사), CCX fc35bda7… 재생성. **남은 것은 CCX 실설치 검증 하나다.**

## 4. 측정 교훈 (이 사이클에서 확립)

- 프로브의 "통과"는 조작이 실제로 일어났음을 함께 증명해야 한다 — 클릭 0회의 "증가 0",
  빈 시퀀스의 "지문 불변"은 무의미한 통과였다(둘 다 1차 실측에서 실제 발생).
- 자동/수동 구분을 체크리스트에 명시하지 않으면 자동화가 있어도 릴리스 때마다 수동
  재확인으로 낭비된다.
