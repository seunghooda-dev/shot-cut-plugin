## 시리얼 키 — 사내에서도 필요하다

배포 빌드(`build:release`)에는 **시리얼 키 게이트가 켜져 있다.** 확인 결과 CCX 번들 안에
`license-overlay`와 `SFS1` 검증이 살아 있다. 즉 **설치한 사람마다 키를 넣어야 패널이 열린다.**

유료 판매를 하지 않아도 이 게이트를 남겨 둘 이유가 있다 — CCX 안에는 **학습 모델·참조 뱅크가
들어 있고**, 파일이 사외로 나가면 그대로 동작한다. 키는 그 경우의 최소 방어선이다.

### 발급

```bash
node scripts/license-issue.mjs --id "홍길동-편집실1" --days 365
```

- `--id`는 **누구/어느 자리인지 알아볼 이름**으로 준다(회수·추적의 유일한 단서다).
- 출력된 `SFS1.`로 시작하는 한 줄을 그 사람에게 전달하고, 패널 첫 화면에 붙여 넣게 한다.
- 개인키는 `~/.shortflow-license/private.key`에만 있다. **저장소에 커밋하지 않는다.**

### 검증된 동작 (2026-08-11 실측 6/6)

| 경우 | 결과 |
|---|---|
| 유효 키 | 통과 (남은 일수 표시) |
| 만료된 키 | 거부 `EXPIRED` |
| 시계를 뒤로 돌림 | 잠금 `CLOCK_ROLLBACK` |
| 서명 위조 | 거부 `SIGNATURE` |
| 빈 키 | 거부 `EMPTY` |
| 접두 위조(`SFS2.`) | 거부 `FORMAT` |

만료 7일 전부터 패널에 경고가 뜬다. 연장은 같은 `--id`로 다시 발급하면 된다.

### 게이트를 끄고 싶다면

`vite.config.*`의 `__SHORTFLOW_RELEASE__`가 `mode === "release"`일 때만 참이다. 게이트 없는
배포본이 필요하면 `npm run build && node scripts/package-ccx.mjs`로 개발 모드 번들을 싸면
되지만, **난독화도 함께 꺼지고 모델·뱅크가 그대로 노출된다.** 권장하지 않는다.

## 원격 PC 문제 진단 — 지속 로그

설치된 PC에서 분할 오류·플러그인 오류가 나면 **플러그인 데이터 폴더의
`shortflow-log-YYYYMMDD.log`**(일자별·7일 보관)를 받아 보면 된다. 활동 로그 전체와
잡히지 않은 오류(uncaught error·unhandled rejection)가 자동 기록된다. 정확한 경로는
패널 부팅 시 로그 탭의 "지속 로그 기록 중 — <경로>" 줄에 찍힌다(통상
`%APPDATA%\Adobe\UXP\PluginsStorage\PPRO\…\PluginData\`). 사용자에게는 "로그 탭 맨 아래
부팅 메시지의 경로에 있는 오늘 날짜 log 파일을 보내 달라"고 안내하면 된다.

## 알아 둘 것

- **AI 기능은 API 키가 필요하다.** 비전 검증·큐시트 판독은 OpenAI 유료 호출이다. AI 설정
  탭에서 키를 저장하고 전송 동의를 켜야 동작하며, 키가 없으면 **무료 경로로 조용히 강등**된다
  (분할은 계속 된다).
- **큐시트는 참고용이다.** 경계를 만들지 않고, 확정된 앞뒤 경계 사이 빈자리에 이미 찾아 둔
  후보가 있을 때만 되살린다. 8뉴스는 방송 미출고가 잦아 큐시트 회수를 켜지 않았다(§CUE-2).
- **5시간 이상 연속 작업하면 새 프로젝트로 옮기는 것이 안전하다.** 시퀀스가 수백 개 쌓이면
  Premiere가 느려지는 것을 실측했다.
