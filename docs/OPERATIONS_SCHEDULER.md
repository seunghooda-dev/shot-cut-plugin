# 자율 스케줄러 — 병목 무발생·개선 무중단 (2026-08-08 사용자 지시)

> "앞으로 병목이 발생하고 개선되지 않게 자체적으로 스케줄러 짜줘" — 이 문서가 그 스케줄러다.
> 매시 점검 크론은 이 문서의 큐를 평가해 최상위 실행 가능 항목을 기동한다. 세션이 재시작되면
> 이 문서부터 읽고 크론(매시 :23)을 다시 건다. 실사고 근거: 2026-08-08 04~19시, "신규 없음 +
> 사용자 부재 + Premiere 열화"가 겹치자 15시간 동안 점검만 반복되고 개선이 멈췄다.

## 원칙 세 가지

1. **대기 조건이 생기면 그 조건이 필요 없는 작업으로 즉시 전환한다.** "변화 없음" 보고만
   남기는 유휴 사이클은 스케줄러 실패다 — 매 사이클 반드시 하나를 실행한다.
2. **백로그는 항상 3개 이상 유지한다.** 소진되면 "발굴 사이클" 자체가 다음 작업이다.
3. **실기(단일 CDP 세션)와 자원이 겹치지 않는 작업은 병렬로 진행한다** — 실기 체인 중에도
   오프라인 분석·문서·다운로드는 돈다(단 빌드(npm run build/check)는 체인 중 금지 — dist 오염).

## 우선순위 큐 (매 사이클 위에서부터 첫 실행 가능 항목을 기동)

| 순위 | 항목 | 실행 가능 조건 |
|---|---|---|
| P0 | 신규 회차 ③ 측정 — §151 오염 검사 → 라벨(에이전트 1차+본인 재검증) → 유료 3실행(§194 신뢰판) → 검문 채점 | 신규 파일 + 패널 정상 + 크레딧 |
| P1 | 예약된 실기 검증(백로그의 [실기] 항목) | 패널 정상 (+유료면 크레딧) |
| P2 | 개선 백로그(아래 표) 중 현재 병목과 무관한 최상위 | 항목별 조건 |
| P3 | 문서·테스트·정합·위생 | 없음 |
| P4 | 발굴 사이클 — 백로그 보충(실측 로그 FP/FN 재분석·코퍼스 확장 탐색·외부 기법 조사) | 없음 |

## 병목 대응 표 (조건 발생 시 전환 규칙)

| 병목 | 전환 |
|---|---|
| 사용자 개입 대기(패널 Load·재기동) | 오프라인·문서·라벨·다운로드 항목으로 전환, 개입 요청은 반복하지 않고 아침 창에 1회 묶음 제안 |
| 크레딧 소진 | 무료 경로 항목만 진행, 충전 감지는 다음 유료 항목 실행 시 실행기 가드가 겸함 |
| 신규 회차 없음 | 코퍼스 심화 — 과거 회차 탐색·다운로드·라벨(홀드아웃 풀 확보) |
| Premiere 열화(42h 실측 ×2)·행 | 오프라인 항목 전환 + 임계 접근 시 사용자 창에 재기동 제안. §192: 재기동은 자동화 가능, Load만 사용자 필요 |
| 실기 체인 실행 중 | 병렬 무해 작업(오프라인 분석·문서·다운로드), 빌드 금지 |

## 정기 실기 유지보수 (2026-08-09 사용자 지시 — 4시간마다)

**"정해진 시간마다 로드 직접 실행하고 프로젝트 재실행"** — 열화·비대를 사후 대응이 아니라
주기 리셋으로 막는다. 크론이 scratchpad `run-maintenance.sh`를 4시간마다 돌린다.

1. **패널 Load 재실행**(`panel-reload.mjs` — connectPanel의 Plugin.load). §192 세션 열화
   (42h에 2회 실측)를 주기적으로 리셋한다.
2. **새 폐기용 프로젝트 로테이션**(`cdt-rotate-project.mjs`) — 시퀀스 누적 예방.
3. **프리뷰 캐시 회수**(`npm run clean:previews -- --apply`).

**실기 체인 중이면 스스로 건너뛴다**(panel.lock 45분 미만) — 회차 중간 개입은 §40-d 단일
세션 원칙을 깨고 그 회차를 무효로 만든다. 다음 주기에 재시도한다.

**§192 정정(2026-08-09 실측)** — "패널 Load는 사용자 클릭이 필요하다"는 반쪽 사실이다.
UDT에 앱 클라이언트가 등록돼 있으면 **스크립트가 Plugin.load를 직접 수행할 수 있다**(오늘
실증). 사용자 개입이 실제로 필요한 경우는 Premiere 앱 자체를 재기동해 UDT 등록이 끊겼을
때뿐이며, 그때는 `udt-app-check-wide.mjs`가 실패로 즉시 드러난다.
