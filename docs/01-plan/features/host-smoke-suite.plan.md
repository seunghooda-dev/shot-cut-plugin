# Host 회귀 스모크 스위트 (host-smoke-suite) — Plan

- 작성: 2026-07-15 (야간 자율 배치, /goal 2번)
- 상태: **완료** — 기본 4종+full 2종, 실기 full 6/6 통과, 런북 §43. 성공 기준 4개 전부 충족.

## 배경

실기(Host) 검증 스크립트 170여 개가 세션 스크래치패드에 흩어져 있고, 세션이 끝나면 소실될 수 있다.
그 과정에서 얻은 footgun 교훈(§40-d 단일 세션 원칙, §25-b UXP 셀렉터 제한, heredoc 이스케이프 소비,
§42-c 트랜잭션 스코프)은 재사용 가능한 형태로 저장소에 박혀 있어야 한다.

## 성공 기준

1. `npm run host:smoke` 한 명령으로 실행되는 회귀 스위트가 저장소 `scripts/host-smoke/`에 존재.
2. 라이브러리가 footgun 방지책을 구조적으로 내장 — 러너가 **한 번만 접속(1회 재부팅)** 후
   모든 체크를 같은 세션에서 실행, 비동기 프로브는 마커+폴링 패턴을 헬퍼로 제공.
3. 기본 체크(비파괴): 부팅·콘솔 0, 12탭 스윕, 호스트 컨텍스트, 핵심 UI 계약.
   `--full`: 자막 SRT 라운드트립 + 트랜스크립트 첨부 E2E(스크래치 시퀀스, 자체 정리).
4. 런북에 사용법·티어 구분 문서화. 게이트(npm run check) 초록 유지.

## 비범위

- 스크래치패드의 일회성 진단 스크립트 전부를 이관하지 않는다(검증 가치가 반복되는 것만).
- CI 통합(Premiere 실기가 필요해 로컬 전용).
