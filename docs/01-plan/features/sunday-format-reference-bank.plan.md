# 일요일 포맷 참조 뱅크 확장 (sunday-format-reference-bank) Planning Document

> **Feature**: 무료 분할 일요일 포맷 커버리지 · **Project**: shortflow-studio · **Date**: 2026-07-21
> **상태**: 계획만 수립 — 사용자 승인 후 착수

## 1. 범위

§72 재구축 후 무료 분할 모델은 전체 46회차 F1 88.0이지만, **일요일 특수 포맷에서만 실패**한다 — 6/21(레터박스) F1 0, 7/12(레터박스) F1 0, 7/19(신형 여성 세트) F1 30.8. 원인은 명확하다: 참조 뱅크(`src/news-anchor-reference-grids.ts`, 7/15 평일 스튜디오 앵커 13장)가 일요일 세트와 화면이 달라 refDist 특징이 전이되지 않고, 후보 수집·모델 발화 모두 막힌다(§71-e 진단). 이 뱅크에 **일요일 포맷 앵커 템플릿을 추가**해 커버리지를 넓히되, 평일 성능(F1 88.0)은 회귀 없이 유지한다.

참고: 3/15·4/5 일요일은 평일형 세트라 이미 F1 100 — 문제는 **레터박스**와 **신형** 두 포맷뿐이다.

## 2. 아키텍처

- **템플릿 추출(오프라인, 신규 스크립트 `scripts/news-train/extract-refs.mjs`)**: 검증 라벨(items.json)의 앵커 시작 시각(start+1~+3s)에서 스캔 캐시 그리드를 뽑는다 — 이미 training-data에 캐시·라벨이 다 있어 프리미어 불필요. 추출본은 §72 프레임 몽타주 파이프라인으로 육안 스팟 확인 후 편입.
  - 추출 대상: 6/21(레터박스)·7/19(일 신형)·7/18(토 신형, 같은 세트) — **7/12(레터박스)·6/28(신형)은 의도적으로 제외**해 같은 포맷의 미학습 회차 전이를 홀드아웃으로 측정.
- **뱅크 구조 — 포맷별 분리(권장)**: 기존 13장에 그냥 합치면 `buildAnchorMatcher`의 셀 가중치(1/(std+8))가 이질 세트 때문에 전역으로 바뀌어 **평일 refDist까지 변형**된다(회귀 위험). 대신 뱅크를 포맷별로 나누고 매처를 뱅크별로 만들어 `distance = min(뱅크별 distance)`로 합성한다 — `src/news-visual-cut.ts`에 `combineAnchorMatchers()` 소함수 추가, 기존 단일 뱅크 경로는 그대로(평일 가중치 불변).
- **학습·추론 정합**: `scripts/news-train/lib.mjs`의 `loadMatcher()`도 동일한 합성 매처를 쓰도록 갱신 — 특징 147(refDist×4)이 학습·추론에서 항상 같은 값(§71-e 교훈).
- **재학습은 기존 게이트 그대로**: `scripts/news-train/train.mjs` 홀드아웃(0709·0711·**0712 레터박스**·**0628 신형**) F1로 커밋 모델을 이겨야만 반영. 매처 변경만으로도 후보 수집이 좋아질 수 있으므로 ①매처만 ②매처+재학습 두 단계로 나눠 측정한다.

## 3. 단계

| 단계 | 내용 | 규모 | 예상 |
|---|---|---|---|
| 1 | extract-refs.mjs — 라벨 시각에서 그리드 추출 + 몽타주 스팟 확인(6/21·7/18·7/19) | 소 | 0.5h |
| 2 | 포맷별 뱅크 상수 추가 + `combineAnchorMatchers` + 단위 테스트 | 소~중 | 0.5~1h |
| 3 | 매처만 변경한 상태로 전체 46회차 offline eval — 일요일 개선·평일 무회귀 확인 | 소 | 0.25h |
| 4 | train.mjs 재학습(게이트) — 이기면 반영, 못 이기면 매처 개선만 커밋 | 소 | 0.25h |
| 5 | 실기 검증 — 미사용 일요일 회차 1개 원클릭 버튼 E2E + 시작 프레임 몽타주 판독 | 중 | 0.5~1h |

**총 예상 2~3시간**. 각 단계 후 `npm run check` 게이트.

## 4. 검증

- **정량(오프라인)**: 홀드아웃 7/12 F1 0→≥60, 6/28 ≥72.7 유지·개선. 평일 홀드아웃(0709·0711) 하락 없음, 전체 F1 ≥88.0 유지. 이 기준 미달이면 반영하지 않는다(게이트).
- **유닛**: combineAnchorMatchers(단일 뱅크와 동치성·min 합성·빈 뱅크 방어) — 기존 1816 그린 유지.
- **실기**: 새 일요일 회차 원클릭 완주(렌더 실패 0) + 시작 프레임 전수 앵커 판독(§72-e 방식).
