### 15. 다국어 패키지 v1 — 언어별 번역 SRT + 유튜브 메타데이터 묶음
- 순수 계층 `src/multilang.ts`: 지원 언어 목록(ko/en/ja/zh 등 6개), 파일명 규칙(`{base}.{lang}.srt`),
  패키지 매니페스트(어떤 언어·파일이 만들어졌는지 Markdown 요약) 빌더.
- 흐름: 자막 탭에서 대상 언어 다중 선택 → 언어마다 기존 translate 액션(AI 큐 경유, cueId/타이밍 보존 검증 재사용)
  → 언어별 SRT를 사용자 선택 폴더에 저장 → 매니페스트 저장. **원본 문서는 변경하지 않는다**(번역 결과는
  커밋하지 않고 SRT 직렬화에만 사용).
- TTS 더빙·언어별 썸네일은 v2로 명시적 제외(비용·검증 부담).
- 검증: 순수 계층 유닛 + Host E2E(피커 스텁, AI 실호출 1개 언어).

### 16. 썸네일 변형 3종 생성·내보내기
- 현 변형 A/B 구조를 3종(A/B/C)으로 확장하고 "변형 전체 SVG 내보내기"(한 번에 3파일) 추가.
- A/B 자동 판단은 하지 않는다(로드맵 명시 — 수동 선택용 파일 생성까지만).
- 검증: 유닛(변형 빌더) + Host 스모크(3파일 저장 확인).

### 17. 자막 버전 스냅샷
- 순수 계층 `src/subtitle-snapshots.ts`(shot-plan-store 패턴): localStorage `shortflow.subtitle-snapshots.v1`,
  프로젝트 키별 스냅샷 {label, createdAt, document}, 상한(키당 10개), 정규화·손상 방어.
- UI: 자막 탭에 "스냅샷 저장"(라벨 자동 = 시각+큐 수) / 목록 / 복원(현재 문서를 스냅샷으로 교체 — undo 가능하게
  컨트롤러 commit 경유) / 삭제.
- 검증: 스토어 유닛 + Host 스모크(저장→편집→복원 라운드트립).

### 18. 플랫폼 업로드 패키지
- "업로드 패키지 내보내기" 버튼: 사용자 폴더 선택 → 현재 자막 SRT + 유튜브 메타데이터(제목·설명·해시태그,
  기존 youtube-metadata 분석 재사용) + 썸네일 SVG(선택 변형) + 에셋 권리 리포트(기존 함수)를
  `{이름}_upload_{ts}/`에 일괄 저장 + README(영상 파일은 내보내기 탭에서 별도 렌더 안내).
- 순수 계층 `src/upload-package.ts`: 파일 구성 계획·README 빌더(호스트 IO 없음).
- 검증: 순수 계층 유닛 + Host E2E(폴더 스텁, 파일 실생성 확인).
