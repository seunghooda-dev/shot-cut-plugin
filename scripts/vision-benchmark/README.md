# 비전 판정 벤치마크 (8뉴스)

실기(Premiere·유료 회차 실행) 없이 **앵커샷 판정만** 재는 고정 프레임 셋. 프롬프트를 고치거나
모델을 바꿀 때 회귀를 몇 분 안에 확인하는 것이 목적이다.

## 이 셋이 재는 것과 재지 않는 것

- **잰다**: 프레임 한 장에 대한 "앵커샷인가" 판정의 정확도, 유형별 실패(대담 게스트·연단
  발언자·리포트 본문 등).
- **재지 않는다**: 후보 생성·회수·병합·재스냅을 포함한 실기 F1. 이 셋이 좋아져도 제품 판정은
  실기로 한다(§162의 "대리 지표를 제품 판단에 쓰지 않는다"와 같은 규율).

## 위치

| 대상 | 경로 |
|---|---|
| 프레임·매니페스트 | `C:\Users\seung\Downloads\vision-benchmark\news8\` (477장 + `manifest.json`, 약 81MB) |
| 빌더 | `scripts/vision-benchmark/build-news8.mjs` |
| 실행기 | `scripts/vision-benchmark/run.mjs` |

프레임은 대용량이라 저장소에 넣지 않는다. 없어지면 빌더로 다시 만들 수 있다(라벨 +
`Downloads/blind` 원본이 있으면 재현된다).

## 구성 (2026-08-04 생성)

477장 · 44회차 — 양성(앵커샷) 320 · 음성(리포트 본문) 150 · **어려운 표본 7**.

어려운 표본은 런북·프롬프트 주석에 남은 **실제 오판 지점**이다. 프롬프트의 각 문장이 이
사례들을 겨냥해 들어갔으므로, 문장을 지우거나 모델을 바꾸면 여기서 먼저 깨진다.

- 대담 게스트 5건(§139 — 1/28 428·456, 4/09 254·282, 3/04 602): 가운데·오른쪽 인물
- 성금 카드 앵커 1건(§134 — 1/28 687): 무료 띠 필터가 잘못 지웠던 **진짜 앵커**
- 연단 발언자 1건(§170-c — 2/19): 칼럼 진행자로 오인했던 유형

## 사용법

```bash
OPENAI_API_KEY=<키> node scripts/vision-benchmark/run.mjs --limit=80
```

옵션 — `--limit=N`(표본 수 제한, 비용 절감) · `--extras=seated|left|none`(프롬프트 단서
A/B) · `--model=<모델>`(모델 비교).

키는 환경변수에서만 읽는다. 제품의 API 키는 secureStorage 안에 있고 밖으로 꺼내지 않는다 —
이 실험 도구는 그 경로와 분리돼 있다.

## 셋을 다시 만들 때

```bash
node scripts/vision-benchmark/build-news8.mjs
```

라벨(`training-data/news-anchor/*.items.json`, corrected가 있으면 우선)과
`Downloads/blind/*.mp4`를 대조해 회차당 최대 6개 아이템을 뽑는다. 이미 있는 파일은
건너뛰므로 회차를 추가한 뒤 다시 돌려도 안전하다.
