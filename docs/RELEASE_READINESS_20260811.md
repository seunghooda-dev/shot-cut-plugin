# 배포 준비 실사 — 2026-08-11

사용자 지시("작업 마무리하고 배포 준비")로 현재 상태를 실사했다. **범위 주의: 이 저장소의
합격 기준은 `INTERNAL_BETA_SCOPE.md`의 "Premiere 내부 베타"다.** 판매·마케팅·SaaS 운영은
명시적으로 범위 밖이므로, 여기서 말하는 "배포"는 **내부 베타 후보(CCX) 배포**를 뜻한다.
그 범위를 넘기려면 별도 판단이 필요하다.

## 2. 실사에서 잡은 배포 차단 항목

### (a) 큐시트 UI 설명문이 사실과 달랐다 — **시정함**

패널 문구가 "아직 분할 판정에는 쓰이지 않고 회차별로 저장만 합니다"였다. 오늘 회수(§7-ax)와
가지치기(§7-bl)를 배선했으므로 **거짓이다.** 사용자가 읽는 화면이라 배포 전 필수 시정이었다.

새 문구는 실제 동작을 그대로 적는다 — 검산 통과 시 방송일자·프로그램별 저장, **참고용으로만
사용**(경계를 만들지 않고 초과분을 걷어내며 빈자리의 기존 후보만 되살림), 유료 고지.

### (b) 큐시트 가지치기가 실기 미검증이다 — **진행 중**

§7-bl은 오프라인 근거만 있다(100 미만 11회차 91.4 → 94.4). 오프라인에는 비전이 없어
과분할이 그대로 남은 상태이므로, 비전이 이미 걷어낸 실기에서는 **깎을 것이 없거나 최악의
경우 맞는 것을 깎을 수 있다.** 과분할 이력 회차(7/16·8/05)와 F1 100 회차(7/22·8/07)를
함께 돌려 판정 중이다. **이 판정 전에는 배포하지 않는다.**

## 4. 사용자 확인이 필요한 것

- **"상용화 배포"의 범위** — 내부 베타 CCX 배포인지, 그 이상(외부 배포·판매)인지.
  후자라면 `INTERNAL_BETA_SCOPE.md`가 범위 밖으로 둔 항목들(라이선스·과금·지원 체계)이
  새로 필요하고, 그것은 이 실사에 포함되지 않았다.
- **8뉴스 큐시트** — §CUE-2에서 회수는 기각됐고 가지치기는 오프라인 +3.6이다. 8뉴스 동결
  지시가 유지되는 한 실기 검증을 못 하므로, 8뉴스에 큐시트를 켤지는 사용자 판단이다.
