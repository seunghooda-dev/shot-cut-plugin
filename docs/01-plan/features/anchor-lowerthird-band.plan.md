# 하단 자막 띠 기하로 과분할 억제 (anchor-lowerthird-band) Planning Document

> **Feature**: FP 억제 4차 시도 — motion(기각)·left-pixel(기각)·skin(기각) 후속, 사용자 제안(2026-07-22) · **Project**: shortflow-studio · **Date**: 2026-07-22
> **전제 지식**: ①하이브리드는 ∪ 결합이라 모델로 FP 제거 불가(§74) ②사람/의상/움직임 기반 무료 신호는 3연속 기각 — 이번 신호는 **방송 그래픽(CG) 기하**라 범주가 다름

## 1. 가설 (사용자 관찰, 배치10 FP 4건 기반)

KBC 8뉴스 앵커샷은 컷 직후 **하단 흰 띠(헤드라인 CG)** 가 뜨고, 그 텍스트는 **항상 한 줄**이다. 반면 FP 유형은 다음 중 하나다.

- **띠 없음**: 항공/현장 footage (news_168 유형)
- **띠 2줄**: 발언자 이름·소속 CG (news_165 연설 유형)
- 띠 위치·높이가 앵커 헤드라인 띠와 다름

확정 후보 시각 t의 리드 창에서 **띠 존재·세로 위치·높이·텍스트 줄 수**를 재면 TP/FP가 갈릴 것이다. 의상·인물·움직임과 무관한 고정 기하라서 §74-d(의상 과민)·§74-e(비디오월 움직임)·§75-c(웜톤 배경)의 기각 원인이 재발하지 않는다.

## 2. 방법 — 실험 먼저, 제품화는 나중에 (§74-d 교훈 유지)

1. **오프라인 실험(스크래치패드)**: 소스 mp4가 남은 회차(Downloads 34개)에서 현행 예측의 TP/FP를 라벨로 판정 → 각 경계 시각 t+{0.5, 2, 4}s 프레임을 ffmpeg raw-gray(480x270)로 추출 → 하단 영역 띠 지표(존재·top·height·줄수) 분포를 TP/FP로 비교.
   - 주의: 96x54 스캔 캐시로는 줄 수 판별 불가 — 실험은 소스 프레임, 제품화 시엔 후보 시각만 고해상 프로브 추가.
   - 일요일 신형 포맷은 띠 기하가 다를 수 있으므로 요일 태그로 분리 집계.
2. **분리도가 있으면** 필터 규칙·임계 스윕(기준: 전체 F1↑, R≥93, 홀드아웃 84.9 무하락) → 통과 시에만 src 제품화(후보 확정 후 밴드 프로브+필터, 유닛, check:news 스냅샷 유지).
3. **분리도가 없으면** 수치만 기록하고 종료(코드 변경 0).

## 3. 성공 기준

- 배치10 FP 4건(news_157·165·168·190 유형) 중 다수를 띠 규칙이 배제하고, TP 통과율 ~100% 유지.
- 전체(소스 보유 회차) F1 상승, R 유지. 홀드아웃 무하락. 미달 시 미반영.

## 4. 리스크

| 리스크 | 대응 |
|---|---|
| 띠가 컷 직후가 아니라 수 초 뒤에 뜸 | 오프셋 3점(0.5/2/4s) 실측으로 신뢰 구간 결정 |
| 일요일 신형 포맷 띠 기하 상이 | 포맷별 분리 집계, 필요 시 포맷별 파라미터 |
| 앵커 리드 중 짧은 2줄 CG(속보 등) 겹침 | TP 분포에서 실측 판단 |
| 제품화 시 고해상 프로브 비용 | 확정 후보에만 적용(회차당 ~10-15프레임, 재스냅과 동급) |

## 5. 실험 결과 (2026-07-22) — ✅ 채택(역방향 규칙)

소스 33회차 377경계(TP 346/FP 31) × 오프셋 {0.5, 2, 4}s 행 프로파일 실측(scratchpad/exp-band-*.mjs).

- **가설 검증**: 몽타주 눈검증에서 사용자 관찰 그대로 확인 — TP는 흰 띠+큰 글자 한 줄, 발언 FP는 파란 2줄 띠, 회견 FP는 흰 2줄, 항공 FP는 무띠.
- **"한 줄 띠 필수" 규칙(정방향)은 기각**: ①헤드라인 띠는 리포트 중에도 계속 떠 있어 footage 경계 FP 다수가 TP와 동일 지표(h37·글리프22) ②흰 티커가 띠에 붙어 현행 TP도 2줄로 잡힘 ③6/03 CG 특집·오프닝은 띠 자체가 없음(늦은 오프셋 6~10s에도) — TP 통과율 78%가 상한.
- **채택 규칙(역방향)**: "흰 띠(평균>115 최장 런 ≥14행@270px)는 있는데 큰 헤드라인 글리프(끊김 없는 어두운 런)가 12행 미만"이 **+2s·+4s 양쪽**에서 감지되면 인용·이름표 띠로 보고 배제. 첫 후보(오프닝)는 면제.
- **성적**: 현행(5월~) TP 오배제 **0/283**, FP 배제 5/24(전부 배치10 유형 — 0513 CG·0519 발언·0521 회견·0610·0617 발언). 구형(1~4월) TP 4 희생(1월 2줄 헤드라인 포맷 — 현재 방송에선 소멸). check:news 회차(0512·0607·0720) 판정 변화 0.
- **한계(설계대로 부분 억제)**: 헤드라인 띠가 계속 떠 있는 footage 경계 FP와 무띠 항공 FP(0521@384)는 이 신호로 구분 불가 — 잔여 경로는 비전 검증(vision-anchor-verify).
- **제품화**: src/news-visual-cut.ts(lowerThirdRowStats·quoteBandFromStats·isQuoteBandStats) + index.ts 원클릭(비전 검증 뒤·재스냅 앞, 480px BMP 2프레임/후보) + lib.mjs(applyQuoteBandFilter, bandprobes 캐시) + eval/regression 반영. 오프라인 전체 71회차 F1 91.9→**92.0**(FP 94→89), 게이트 1829·check:news 통과.
