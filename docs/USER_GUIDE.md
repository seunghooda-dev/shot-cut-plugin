# ShortFlow Studio 내부 베타 사용 가이드

- 기준일: 2026-07-15 · 패키지: `release/ShortFlow-Studio-1.0.0.ccx` (SHA-256 `872d87d4823bda6c46f9f6761a90b761f898f304499dad8934090f6754f1080b`)
- 대상: Premiere Pro 내부 베타 참가자. 이 플러그인은 로컬 도구이며 판매·서버 운영 기능이 없습니다.

## 설치

1. Premiere Pro를 종료한 상태에서 CCX 파일을 더블클릭해 Creative Cloud로 설치하거나, UXP Developer Tools로 `dist/` 폴더를 직접 로드합니다(개발 로드).
2. Premiere를 실행하고 창 메뉴에서 ShortFlow Studio 패널을 엽니다.

## 시작 전 준비 — AI 설정 (12번 탭)

- AI 기능(STT·자막 AI·자동 컷·인물 추적·이미지)은 OpenAI API를 사용하며 **사용자 본인의 API 키로 과금**됩니다.
- 키는 **AI 설정 탭에서 직접 입력**하세요. Premiere의 secureStorage에만 저장되고, 요청은 `api.openai.com`으로만 나갑니다.
- AI 기능 첫 사용 시 동의 확인이 뜹니다. 자막 텍스트는 항상 "신뢰할 수 없는 데이터"로 취급되어 프롬프트 명령으로 해석되지 않습니다.

## 13개 탭 한눈에

| # | 탭 | 하는 일 |
|---|---|---|
| 01 | 뉴스 분할 | 뉴스 전체 방송을 보도 아이템별 시퀀스 `오늘일자_news_NN`로 자동 분할. 분석(경계+제목) → 앵커 샷 컷 스냅·병합 기사 내부 분할·짧은 리드 병합 → 시퀀스 생성(같은 날짜는 번호 이어붙임) → 일괄 내보내기(AME 있으면 대기열, 없으면 Premiere 직접 렌더). 확신 높은 앵커 샷은 자동 학습되어 다음 분석의 참조로 쓰입니다 |
| 02 | QC | 시퀀스·미디어 상태 검사와 문제 항목 리포트, 작업 전 안전 점검 |
| 03 | 숏폼 생성 | 세로형(9:16) 숏폼 생성. AI 자동 컷(하이라이트 후보 스캔→선택→일괄 생성), 인물 추적 프레이밍, 하이라이트 릴(16:9), 뉴스 스타일(fit), 스타일 학습(SRT 쌍 등록), 생성 후 프레이밍 조정(X/Y/줌) |
| 04 | 마커 배치 | 마커 검색과 일괄 생성 |
| 05 | 자동 편집 | STT 기반 무음 컷 추천, 펀치인, BGM 삽입·비트 스냅·자동 덕킹, 클립 모션(등장/퇴장 등) |
| 06 | 음악·효과음 | 로컬 폴더 동기화 에셋 라이브러리, 미리듣기, 타임라인 삽입, 에셋 권리(출처·라이선스) 기록 |
| 07 | TTS·STT | 시퀀스 오디오→STT(긴 영상은 자동 분할 전사), 자막 편집기(실행 취소·분할·병합·숨김), SRT/Whisper JSON 입출력, AI 자막 도구(줄바꿈·맞춤법·번역·인터뷰 발췌·편집 구성안·유튜브 메타데이터), **텍스트 패널로 보내기**, **스냅샷 저장/복원**(버전 관리), **다국어 SRT 내보내기**(6개 언어 일괄 번역), TTS 생성·삽입 |
| 08 | AI 레퍼런스 | 레퍼런스 보드 — 이미지 가져오기·AI 이미지 생성·프롬프트 메모·태그 |
| 09 | 브랜드 MOGRT | 브랜드 킷 관리와 MOGRT 삽입 |
| 10 | 썸네일 | 제목·배지·색 구성으로 썸네일 변형 제작(최대 3종), SVG 미리보기 저장, **변형 전체 일괄 내보내기** |
| 11 | 내보내기 | 프리셋 선택 후 Media Encoder 대기열 추가 또는 즉시 내보내기, **업로드 패키지 내보내기**(SRT·메타데이터·썸네일·권리 리포트 묶음) |
| 12 | AI 설정 | API 키·동의·AI 작업 대기열 관리, 일일 요청·비용 한도 |
| 13 | 로그 | 활동 로그와 진단 정보(민감정보 제거) |

### 뉴스 분할 빠른 사용법

1. 뉴스 방송이 담긴 시퀀스를 활성화하고 **TTS·STT 탭에서 시퀀스 STT**를 실행합니다.
2. **뉴스 분할 탭**에서 "보도 아이템 분석"을 누릅니다 — 진행률 바로 경계 스캔·앵커 샷 분류 단계를 확인할 수 있습니다.
3. 목록에서 아이템(구간·제목)을 확인하고 "아이템 시퀀스 생성"을 누릅니다. 같은 날짜에 이미 만든 아이템이 있으면 번호가 이어집니다.
4. "일괄 내보내기"는 내보내기 탭에서 선택한 프리셋·저장 폴더를 사용합니다. Media Encoder가 없는 PC에서는 Premiere가 순차 직접 렌더합니다(파일명 = 시퀀스 이름).

## 추천 워크플로 — 원본에서 숏폼까지

1. **자막 만들기**: 원본 시퀀스를 활성화하고 TTS·STT 탭에서 시퀀스 STT를 실행합니다. 20분이 넘는 영상도 자동으로 분할 전사됩니다.
2. **후보 스캔**: 숏폼 생성 탭의 AI 자동 컷에서 하이라이트 후보를 스캔하고 쓸 구간을 선택합니다.
3. **생성**: 자동 컷 생성을 누르면 구간마다 인물 위치를 추적해 9:16 프레이밍으로 숏폼 시퀀스를 만듭니다. 같은 구간을 다시 생성하면 감지 캐시로 비전 비용 없이 재생성됩니다.
4. **미세 조정**: 프레이밍이 아쉬우면 "프레이밍 조정"에서 숏폼을 선택해 X/Y·줌을 재적용하거나 원본 프레이밍으로 복원합니다.
5. **화면 자막(캡션)**: TTS·STT 탭의 **"텍스트 패널로 보내기"**로 자막을 Premiere 트랜스크립트로 첨부한 뒤, Premiere 텍스트 패널에서 **"캡션 만들기"** 한 번이면 스타일 캡션 트랙이 생깁니다.
6. **내보내기**: 내보내기 탭에서 프리셋을 선택해 렌더링합니다.

숏폼 감각을 학습시키려면 — 과거에 만든 (원본 SRT, 숏폼 SRT) 쌍을 "스타일 학습"에서 한 번에 선택하세요. 어느 쪽이 원본인지는 자동 판별되고, 등록된 예시는 다음 자동 컷 후보 선정에 반영됩니다.

## 알려진 제한 (플랫폼 제약)

- **썸네일 PNG/JPG 내보내기 불가** — 현 Premiere UXP가 Canvas 이미지 합성을 제공하지 않아 SVG 미리보기 저장으로 대체합니다.
- **화면 그래픽 텍스트 자동 입력 불가** — MOGRT 텍스트 파라미터가 API에 노출되지 않습니다. 뉴스 스타일은 문구를 텍스트 마커로 제공하며, 발화 자막은 위의 트랜스크립트→캡션 경로를 쓰세요.
- **캡션 트랙 자동 생성 불가** — 캡션 트랙 생성 API가 없어 "캡션 만들기" 클릭 한 번이 필요합니다(트랜스크립트 첨부까지는 자동).
- 안전 규칙: 타임라인 변경은 잠금 트랙·구간 충돌을 검사하고 실패 시 롤백합니다. 그래도 중요한 프로젝트는 사본에서 시험하세요.
- 자막은 **시퀀스별**로 관리됩니다 — 숏폼을 생성하면 활성 시퀀스가 생성물로 바뀌어 자막 편집기가 그 시퀀스의(비어 있는) 문서를 보여줍니다. 원본 시퀀스를 다시 활성화하면 작업하던 자막이 자동 복원됩니다.

## 문제 신고

로그 탭의 활동 로그(민감정보는 자동 제거)와 함께 재현 절차를 알려주세요. AI 관련 문제는 AI 설정 탭의 대기열 상태도 함께 캡처하면 진단이 빨라집니다.
