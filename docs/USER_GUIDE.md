# ShortFlow Studio 내부 베타 사용 가이드

- 기준일: 2026-07-15 · 패키지: `release/ShortFlow-Studio-1.0.0.ccx` (SHA-256 `36a94311dad4b8b57cc994826dd879db8ea69e860f99c80294f32410955e0ee7`)
- 대상: Premiere Pro 내부 베타 참가자. 이 플러그인은 로컬 도구이며 판매·서버 운영 기능이 없습니다.

## 설치

1. Premiere Pro를 종료한 상태에서 CCX 파일을 더블클릭해 Creative Cloud로 설치하거나, UXP Developer Tools로 `dist/` 폴더를 직접 로드합니다(개발 로드).
2. Premiere를 실행하고 창 메뉴에서 ShortFlow Studio 패널을 엽니다.

## 시작 전 준비 — AI 설정 (11번 탭)

- AI 기능(STT·자막 AI·자동 컷·인물 추적·이미지)은 OpenAI API를 사용하며 **사용자 본인의 API 키로 과금**됩니다.
- 키는 **AI 설정 탭에서 직접 입력**하세요. Premiere의 secureStorage에만 저장되고, 요청은 `api.openai.com`으로만 나갑니다.
- AI 기능 첫 사용 시 동의 확인이 뜹니다. 자막 텍스트는 항상 "신뢰할 수 없는 데이터"로 취급되어 프롬프트 명령으로 해석되지 않습니다.

## 12개 탭 한눈에

| # | 탭 | 하는 일 |
|---|---|---|
| 01 | QC | 시퀀스·미디어 상태 검사와 문제 항목 리포트, 작업 전 안전 점검 |
| 02 | 숏폼 생성 | 세로형(9:16) 숏폼 생성. AI 자동 컷(하이라이트 후보 스캔→선택→일괄 생성), 인물 추적 프레이밍, 하이라이트 릴(16:9), 뉴스 스타일(fit), 스타일 학습(SRT 쌍 등록), 생성 후 프레이밍 조정(X/Y/줌) |
| 03 | 마커 배치 | 마커 검색과 일괄 생성 |
| 04 | 자동 편집 | STT 기반 무음 컷 추천, 펀치인, BGM 삽입·비트 스냅·자동 덕킹, 클립 모션(등장/퇴장 등) |
| 05 | 음악·효과음 | 로컬 폴더 동기화 에셋 라이브러리, 미리듣기, 타임라인 삽입, 에셋 권리(출처·라이선스) 기록 |
| 06 | TTS·STT | 시퀀스 오디오→STT(긴 영상은 자동 분할 전사), 자막 편집기(실행 취소·분할·병합·숨김), SRT/Whisper JSON 입출력, AI 자막 도구(줄바꿈·맞춤법·번역·인터뷰 발췌·편집 구성안·유튜브 메타데이터), **텍스트 패널로 보내기**, TTS 생성·삽입 |
| 07 | AI 레퍼런스 | 레퍼런스 보드 — 이미지 가져오기·AI 이미지 생성·프롬프트 메모·태그 |
| 08 | 브랜드 MOGRT | 브랜드 킷 관리와 MOGRT 삽입 |
| 09 | 썸네일 | 제목·배지·색 구성으로 썸네일 변형 A/B 제작, SVG 미리보기 저장 |
| 10 | 내보내기 | 프리셋 선택 후 Media Encoder 대기열 추가 또는 즉시 내보내기, Safe Zone 가이드 |
| 11 | AI 설정 | API 키·동의·AI 작업 대기열 관리 |
| 12 | 로그 | 활동 로그와 진단 정보(민감정보 제거) |

## 추천 워크플로 — 원본에서 숏폼까지

1. **자막 만들기**: 원본 시퀀스를 활성화하고 TTS·STT 탭에서 시퀀스 STT를 실행합니다. 20분이 넘는 영상도 자동으로 분할 전사됩니다.
2. **후보 스캔**: 숏폼 생성 탭의 AI 자동 컷에서 하이라이트 후보를 스캔하고 쓸 구간을 선택합니다.
3. **생성**: 자동 컷 생성을 누르면 구간마다 인물 위치를 추적해 9:16 프레이밍으로 숏폼 시퀀스를 만듭니다. 같은 구간을 다시 생성하면 감지 캐시로 비전 비용 없이 재생성됩니다.
4. **미세 조정**: 프레이밍이 아쉬우면 "프레이밍 조정"에서 숏폼을 선택해 X/Y·줌을 재적용하거나 원본 프레이밍으로 복원합니다.
5. **화면 자막(캡션)**: TTS·STT 탭의 **"텍스트 패널로 보내기"**로 자막을 Premiere 트랜스크립트로 첨부한 뒤, Premiere 텍스트 패널에서 **"캡션 만들기"** 한 번이면 스타일 캡션 트랙이 생깁니다.
6. **내보내기**: 내보내기 탭에서 프리셋을 선택해 렌더링합니다.

숏폼 감각을 학습시키려면 — 과거에 만든 (원본 SRT, 숏폼 SRT) 쌍을 "스타일 학습"에서 한 번에 선택하세요. 어느 쪽이 원본인지는 자동 판별되고, 등록된 예시는 다음 자동 컷 후보 선정에 반영됩니다.

## 알려진 제한 (플랫폼 제약)

- **썸네일 PNG/JPG 내보내기 불가** — 현 Premiere UXP가 Canvas 이미지 합성을 제공하지 않아 SVG 미리보기 저장으로 대체합니다.
- **화면 그래픽 텍스트 자동 입력 불가** — MOGRT 텍스트 파라미터가 API에 노출되지 않습니다. 뉴스 스타일은 문구를 텍스트 마커로 제공하며, 발화 자막은 위의 트랜스크립트→캡션 경로를 쓰세요.
- **캡션 트랙 자동 생성 불가** — 캡션 트랙 생성 API가 없어 "캡션 만들기" 클릭 한 번이 필요합니다(트랜스크립트 첨부까지는 자동).
- 안전 규칙: 타임라인 변경은 잠금 트랙·구간 충돌을 검사하고 실패 시 롤백합니다. 그래도 중요한 프로젝트는 사본에서 시험하세요.

## 문제 신고

로그 탭의 활동 로그(민감정보는 자동 제거)와 함께 재현 절차를 알려주세요. AI 관련 문제는 AI 설정 탭의 대기열 상태도 함께 캡처하면 진단이 빨라집니다.
