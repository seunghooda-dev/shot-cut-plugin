# Plan — 긴 아이템 재탐색으로 미검출 회수 (long-item-rescue)

> §100 처방. 신규 회차에서 무너진 재현율을 **이상 구간에서만** 회수한다. 정상 회차는 건드리지 않는다.

## 1. 문제

미학습 신규 회차 2026-07-23에서 무료 분할이 무너졌다 — 정답 12아이템 중 **4개**만 생성(F1 47.1, 실기 비전 ON 50.0). 직전 회차 7/20·7/21·7/22는 F1 100이다.

§100 실측 요약.

- 참조 뱅크(평일 13장)가 이 회차 앵커샷을 못 알아본다 — 최소거리 0.0784(7/22) → **0.1179**(7/23).
- 뱅크 거리가 **학습 모델의 특징이기도 해서** 후보 생성과 모델이 **같은 원인으로 함께** 무너진다(모델 시작 12→0). 이중화처럼 보였지만 이중화가 아니다.
- 매처는 "왼쪽에 앵커가 있는가"가 아니라 **"화면 전체가 참조와 닮았는가"**를 잰다 — 가중치 `1/(√std+8)` 아래에서 **배경이 총 가중치의 68%**를 차지한다. 놓친 8샷과 잡은 4샷이 육안으로 구분되지 않는 이유다.

## 2. 기각된 대안 (실험 완료 — 다시 시도하지 말 것)

| 시도 | 결과 | 판정 |
|---|---|---|
| 모델에서 뱅크 거리 특징 제거 후 재학습 | 홀드아웃 최고 77.8 < 기준선 82.6, 7/23도 47.1→44.4 | **기각** — 현재 특징 공간에 뱅크 외 판별 정보가 없다 |
| 앵커 영역만 매칭(열6 행0~8) + 재학습 | 7/23 47.1→75.0이지만 전량 94.4→**91.2**, 망가진 회차 4→**11** | **기각** — 1회차 살리고 7회차 깬다 |
| 전체화면 후보 ∪ 영역 후보 | 7/23 **37.5**로 악화 | **기각** — 거리 척도가 달라 적응 임계가 깨진다 |
| (2026-07-21 선행) 왼쪽 영역 필터 | 모든 임계에서 하락 — 왼쪽 열에 앵커 **의상**이 들어가 매일 바뀐다 | **기각**([anchor-left-feature](anchor-left-feature.plan.md)) |
| (2026-07-21 선행) 시간적 움직임 신호 | TP/FP 중앙값이 겹침 — 스튜디오 배경이 애니메이션 비디오월 | **기각**([anchor-motion-signal](anchor-motion-signal.plan.md)) |

**교훈**: 고정 참조 13장 + 전역 가중치 하나로는 "배경 강건성"과 "앵커 특이성"을 동시에 만족시킬 수 없다. 매처 자체를 손보는 길은 네 번 막혔다.

## 3. 채택 방향 — 이상 구간 재탐색

**핵심 관찰**: 진짜 앵커들은 후보 목록에서 **사라진 게 아니라 임계 아래로 밀려 있다.** 7/23 정답 12개의 거리 순위는 상위 100 안에 8개, 150 안에 11개다(7/22는 12개 전부 상위 100 안).

그러나 전 구간에서 임계를 낮추면 후보가 150개로 늘어 비전 비용이 9배가 된다. 대신 **아이템 길이 이상**을 신호로 삼아 그 구간에서만 다시 찾는다.

### 알고리즘 (오프라인 검증 완료)

1. 확정된 아이템 중 길이가 `MAX_SPAN`(잠정 180s)을 넘는 것을 고른다.
2. 그 구간 안쪽(양 끝 `MIN_SPAN` 여유 제외)에서 **뱅크 거리가 가장 낮은 지점 하나**를 뽑아 후보로 추가한다.
3. 쪼개진 두 구간이 여전히 `MAX_SPAN`을 넘으면 반복한다.
4. 추가된 후보는 **기존 비전 검증 경로를 그대로 통과**시킨다(오배제 0 확립 — §92).

### 실측 결과 (7/23, maxSpan 180 · minSpan 25)

| | 값 |
|---|---|
| 추가 후보 | **5개**(비전 프레임 20장 — 기존 68장 대비 +29%) |
| 그중 진짜 경계 | 3개 |
| 회수 | 4/12 → **7/12** |

### 회귀 위험이 구조적으로 낮다

코퍼스 정답 아이템 **937개 중 180s 이상은 8개(0.9%)**, 8개 회차에만 존재한다(3/06 236s, 6/03 328s, 6/29 288s 등). 즉 **99.1%의 아이템은 이 경로를 아예 지나지 않는다.** 진짜 긴 아이템에는 후보 1~2개가 더 붙지만 비전이 걸러낸다 — 그리고 비전 OFF 사용자를 위해 **비전이 켜져 있을 때만** 발동시키는 안을 우선 검토한다(무료 경로 정밀도 보호).

## 4. 목표

- **주 목표**: 7/23 무료 경로 F1 **47.1 → 70 이상**, 코퍼스 전량 **94.4 무하락**.
- **부 목표**: 비전 프레임 증가 **+50% 이내**.
- **비목표**: 매처·모델 변경(위 5종 전부 기각), 새 특징 도입, 모닝와이드 지원.

## 5. 미해결 질문 (Design 단계에서 결정)

- `MAX_SPAN` 값 — 180s는 7/23 한 회차로 고른 값이다. 코퍼스 전량 스윕으로 확정할 것.
- **비전 OFF일 때 발동시킬 것인가.** 발동하면 무료 경로 FP가 늘 수 있다(추가 후보 5개 중 2개가 가짜였다). 잠정안은 "비전 ON에서만".
- 재귀 깊이 상한 — 무한 분할 방지.
- 7/23에서 **5개는 여전히 회수 안 된다**(7/12). 나머지는 이 방식의 한계인지, `minSpan` 조정으로 더 잡히는지 확인 필요.

## 7. 후순위로 남기는 것

- **참조 뱅크 성장**(사용자가 확인한 결과를 로컬 참조로 승격) — 근본 해법이지만 오답 학습·뱅크 오염 위험이 있고 승인 UI 설계가 선행돼야 한다. 위 재탐색이 목표를 달성하면 우선순위가 내려간다.
- **새 특징 도입**(인물 위치·고해상 스캔) — 비용이 크고 §100 처방 ④로 별도 관리.
